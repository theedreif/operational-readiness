# Claim → Evidence Map

**Pass Four — Mechanical traceability for the Ed Reif Field System**

This document connects public-facing statements about Ed Reif's work to the concepts, publications, applications, evidence, and provenance that support them.

The governing rule is simple:

> **No claim without a trail.**

A claim should be strong enough to be useful and narrow enough to be evidenced.

---

## Traceability Model

```text
CLAIM
  ↓
CONCEPT
  ↓
PUBLICATION / ARTIFACT
  ↓
APPLICATION
  ↓
EVIDENCE
  ↓
PROVENANCE
```

The reverse path should also work:

```text
SOURCE → EVIDENCE → APPLICATION → CONCEPT → SUPPORTED CLAIM
```

This map does not convert association into employment, analysis into endorsement, field evidence into ownership, or lived experience into professional engagement.

# Usage Rules

Use this map when writing:
- biographies
- speaker profiles
- portfolio copy
- AI / search structured data
- book descriptions
- repository documentation
- professional summaries
- media pitches
- case-study introductions

Before publishing a new factual professional claim:

```text
1. IDENTIFY THE CLAIM
2. LOCATE THE CONCEPT
3. LOCATE THE ARTIFACT
4. LOCATE THE APPLICATION
5. LOCATE THE EVIDENCE
6. CHECK THE PROVENANCE
7. NARROW THE WORDING IF THE TRAIL DOES NOT SUPPORT IT
```

A stronger-sounding statement is not better if its provenance is weaker.
