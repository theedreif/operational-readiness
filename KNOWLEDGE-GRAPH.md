# ED REIF KNOWLEDGE GRAPH

**Operational Readiness · Judgment Under Uncertainty · Decision Science · Autonomous Systems · Field Learning**

> I build capability, not courses.  
> If it cannot survive the field, it does not count.

This file is the connective layer for the Ed Reif Field System. It maps concepts to tools, publications, applications, field experience, public archives, and provenance.

It does not redefine the system architecture. The canonical governance record is the [Ed Reif Field System Manifest v1.0](https://github.com/theedreif/theedreif/blob/main/FIELD-SYSTEM.md):

> **Six Worlds = ORIGIN · Seven Doors = OPERATION · One Field System = SYSTEM**

> **BUILD → DECIDE → POSITION → COMMUNICATE → PROVE → UPDATE → DEPLOY**

It is not a claim that every experience is intellectual property. Its purpose is to make relationships visible and evidence traceable.

## 13. Provenance Matters

Every node should answer:

1. **What is it?**
2. **Who created it?**
3. **What relationship did Ed have to it?**
4. **Where is the public evidence?**
5. **What does the evidence actually establish?**

Use the repository's [Provenance Standard](./PROVENANCE.md).

Relationship labels include:
- employed engagement
- client engagement
- independent analysis
- speculative proposal
- publication
- public field evidence
- lived-experience archive

Evidence should establish the relationship without implying employment, endorsement, authorship, ownership, or exclusivity that the source does not support.
