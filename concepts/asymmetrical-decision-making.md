# Asymmetrical Decision-Making

## Definition
**Asymmetrical Decision-Making** is Ed Reif's applied decision framework for structuring exposure so downside is bounded while meaningful upside and future options remain available.

> **You cannot control the cards. You can design the bet.**

## Core Model
**FLOOR → ODDS → OPTIONS → UPSIDE → EVIDENCE**

The framework asks:
- What can I lose?
- Can I improve the odds?
- What options remain?
- Is the upside meaningfully asymmetric?
- What evidence would make me change the position?
