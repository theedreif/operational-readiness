# Frameworks

Reusable models for designing and observing judgment under uncertainty.

## Judgment at the Edge

> **SIGNAL → CONDITION → LIMIT → DECISION → EVIDENCE**

**Signal:** What changed or demands attention?  
**Condition:** What is true about the operating environment now?  
**Limit:** What constraint, boundary, rule, capability, or uncertainty matters?  
**Decision:** What action is justified?  
**Evidence:** What demonstrates the decision and its result?

## DFR Decision Loop

> **NOTICE → INTEGRATE → PRIORITIZE → DECIDE → DEFEND**

The framework emphasizes not only selecting an action but being able to defend the reasoning behind it.
