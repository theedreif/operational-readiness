# Field Tools

This area will contain compact, reusable tools for performance environments: decision cards, scenario templates, observation guides, after-action prompts, and readiness checks.

The design constraint is simple:

> **If the tool cannot survive the field, it does not count.**

## Published Field Tools

### [Field Tool 002 — The 45-Second Rule](./45-second-rule.md)

**FIND → UNDERSTAND → ACT**

A point-of-need design test: can a trained operator locate, comprehend, and use critical information within 45 seconds under realistic field conditions?

### [Field Tool 003 — Scenario Design Canvas](./scenario-design-canvas.md)

**MISSION → SIGNAL → FRICTION → LIMIT → DECISION → CONSEQUENCE → EVIDENCE**

A practical canvas for converting content into realistic decision environments where judgment can be practiced, observed, and debriefed.

### [Field Tool 004 — Operational Readiness Review](./operational-readiness-review.md)

**MISSION → CAPABILITY → CONDITIONS → PERFORMANCE → EVIDENCE → GAP → ACTION**

An evidence-based review that replaces “Did they complete the training?” with “What evidence says they can actually perform under the conditions that matter?”
